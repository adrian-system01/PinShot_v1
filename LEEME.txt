PINSHOT
=======

PinShot usa Avalonia y puede compilarse para Windows, Linux y macOS. Inicia la aplicación y déjala abierta; cuando una imagen se copie al portapapeles, aparecerá una ventana flotante. Una captura nueva cierra la anterior sin guardarla.

CAPTURAS
- Windows: Win+Mayús+S y elige copiar.
- Linux: Impr Pant o la herramienta de captura del escritorio, configurada para copiar.
- macOS: Cmd+Mayús+4; si la captura se guarda como archivo, usa una opción que la copie al portapapeles.

COMPILAR EN WINDOWS
- Compilar.bat: publica con runtime compartido de .NET.
- Compilar_Independiente.bat: incluye el runtime de .NET.
- dotnet test .\PinShot.Tests\PinShot.Tests.csproj: pruebas portables del núcleo.

PUBLICAR EN OTRAS PLATAFORMAS
dotnet publish .\PinShot.Desktop\PinShot.Desktop.csproj -c Release -r linux-x64 --self-contained true
dotnet publish .\PinShot.Desktop\PinShot.Desktop.csproj -c Release -r osx-arm64 --self-contained true
Para Mac Intel usa el RID osx-x64.

Los datos se guardan localmente en la carpeta de datos de aplicaciones del usuario, dentro de PinShot. Configuración permite exportar e importar respaldos ZIP.

El menú del icono de bandeja permite abrir la biblioteca, crear notas, abrir Configuración o salir, cuando el escritorio ofrece soporte para bandejas. En macOS usa el menú del icono, ya que el clic directo no está soportado por Avalonia.

Limitaciones actuales: el portapapeles se sondea mientras la app está abierta; el inicio automático y la captura global nativa aún no están migrados. AI Enhance/Real-ESRGAN tampoco está integrado; los perfiles de recursos solo calculan límites para el futuro.
