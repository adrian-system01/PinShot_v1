PinShot
========

USO DIARIO
1) Haz doble clic en "Iniciar PinShot.lnk".
2) Busca el icono de PinShot en el area de notificaciones (flecha ^ junto al reloj).
3) Toma una captura (Win+Mayus+S) y aparecera flotando.

Si "Iniciar PinShot.lnk" no encuentra una copia compilada, abrira automaticamente
Compilar_Independiente.bat. Esa copia no requiere tener .NET instalado.

COMPILACION
- Compilar.bat: version local que requiere el runtime de .NET.
- Compilar_Independiente.bat: version independiente (ocupa mas espacio).

Icono de la bandeja (clic derecho):
- Nueva nota
- Lista de notas
- Configuracion
- Iniciar con Windows

Doble clic en el icono = abrir la lista de notas.

Atajos en la captura
- Ctrl + rueda ........ zoom (hacia el cursor)
- Arrastrar ........... mueve la ventana (sin zoom) / mueve la imagen (con zoom)
- Shift + arrastrar ... mueve la ventana aunque haya zoom
- Alt + rueda ......... cambia la opacidad
- Doble clic .......... resetea zoom
- N ................... abre/cierra el cuadro de notas
- Ctrl+L .............. abre la lista de notas (boton 📚 en la captura)
- Ctrl+S .............. guarda en la lista de notas (captura + texto)
- Ctrl+Mayus+S ........ guardar como archivo PNG/JPG
- Ctrl+C .............. copiar imagen
- Clic derecho ........ menu
- Esc ................. cerrar

Notas guardadas: %LOCALAPPDATA%\PinShot\Notas  (una carpeta por nota)
Si no aparece nada: %LOCALAPPDATA%\PinShot\log.txt
